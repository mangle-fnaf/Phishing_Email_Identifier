# Phishing Email Identifier

This project aims to classify phishing vs. legitimate emails using Python and machine learning techniques. The repository currently contains early exploratory analysis and dataset preparation. Additional components will be added as development continues.

## What’s Included
- Jupyter Notebook for EDA
- Raw dataset (ignored from Git history)
- Basic preprocessing workflow

## Planned Additions
- TF-IDF feature extraction
- Logistic Regression / Random Forest models
- Evaluation metrics and confusion matrix
- Cleaned pipeline structure in /src

**Raw dataset can be found on Kaggle; this cannot be uploaded to GitHub due to the size of the file.
